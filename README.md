- Руковожу **отделом продаж** онлайн-школы детского IT-образования: две линии — операторы и менеджеры демо-уроков.
- Автоматизирую рутину отдела с помощью **ИИ-агентов**: отчёты, контроль качества, аналитика воронки, обратная связь команде.
- Снимаю с себя ручную работу, чтобы освободить голову под стратегию и рост выручки — без раздувания штата.
- Прихожу из управления, а не из разработки: задачу формулирую как руководитель, решение собираю с ИИ.

### 💡 Подход

Вайб-кодинг: формулирую задачу словами, ИИ помогает собрать рабочее решение. Фокус — на пользе для бизнеса, а не на технологиях ради технологий. Главный вывод: один человек с ИИ собирает систему, которая реально экономит время команды.
